# Math Quest v3.0｜國七數學勇者

繁體中文數學 RPG 學習網站，使用原創、可程式化驗證的題目模板。**不是翰林教科書題目重製版**，章節順序依類翰林版學習架構整理。

## 已納入的九個主要單元

| 學期 | 單元 |
| --- | --- |
| 七上 | 1. 數與數線 |
| 七上 | 2. 標準分解式與分數運算 |
| 七上 | 3. 一元一次方程式 |
| 七下 | 1. 二元一次聯立方程式 |
| 七下 | 2. 直角坐標與二元一次方程式圖形 |
| 七下 | 3. 比例 |
| 七下 | 4. 一元一次不等式 |
| 七下 | 5. 統計圖表與統計數據 |
| 七下 | 6. 線對稱與三視圖 |

主要參考：https://www.junyiacademy.org/topics/h-m7a

## 功能
- 9 個闖關地圖，依序解鎖
- 各關基礎／進階／挑戰三級原創隨機題型
- 整數運算、分數、方程式、聯立、坐標、比例、不等式、統計及幾何的題目模板
- 血量、連擊、XP、擊敗怪物數量
- 提示、逐題解析、錯題復仇
- localStorage 保存進度（限同一瀏覽器）
- 自適應手機與桌面畫面

## 目前限制／後續待補
- 目前是九個單元的**題庫初版**，不是每個細節、每一節都有足量覆蓋：尚須增加科學記號、完整指數律、統計圖表判讀、圖像化三視圖、線對稱作圖、跨章長篇段考題、非選擇題及學習診斷。
- 部分應用題已加強，但完整段考題型仍需要更多人工審題與驗證。
- localStorage 不跨裝置，清除瀏覽器資料會失去進度。
- 請依實際使用的翰林教材年度確認章節與學習順序。

## 本機測試
`npx wrangler dev`

## Cloudflare Workers
`npx wrangler login`
`npx wrangler deploy`

Worker 名稱是 `math-game`，靜態資源位置為 `public/`。若 Cloudflare 已連結 GitHub 自動部署，推送至 main 後仍需查看 Cloudflare Builds / Deployments 是否成功，不能只憑 GitHub 提交推論正式站已更新。
