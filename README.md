# Math Quest 4.0｜國七數學闖關島

從 RPG 血量戰鬥改成**關卡地圖與益智解謎**。主程式：`public/index.html`。

## 新版功能
- 七上、七下 **9 個單元**，每單元 6 關，共 54 關
- 逐關解鎖、每關 1–3 顆星、章節完成解鎖下一章
- 七上第一章的 6 種關卡：
  1. 數線尋寶：點選正負數的數線位置
  2. 數字排序：按正確順序選擇數字卡片
  3. 密碼寶箱：3 道隨機數學題
  4. 等式天平：輸入等式缺失的數
  5. 冰原迷宮：4 道隨機題
  6. 章節大挑戰：5 道綜合題
- 其他八個章節先使用相同六關地圖與分級隨機題庫，尚未完成各章專屬互動謎題
- 進度、星級、錯題紀錄儲存在瀏覽器 localStorage
- 手機／平板／桌面排版

## 版本安全
- 原 RPG v3 原始頁面保存在 `archive/rpg-v3.html`。
- v4 使用新的 `math-quest-puzzle-v4` localStorage key，不會抹除 v3 進度。
- 需要回復舊版時，可將備份 HTML 放回 `public/index.html`。

## 部署
Cloudflare Workers 靜態網站已設定在 `wrangler.jsonc`：
```bash
npx wrangler login
npx wrangler deploy
```
若已將 Cloudflare Workers 與 GitHub 的 main 分支連結，請到 Cloudflare Dashboard 確認此次 commit 的 build/deployment 成功；GitHub 推送並不代表 Cloudflare 部署完成。

## 限制
- v4 是**可試玩的第一輪改版**，不是 54 種不同遊戲。章節 2–9 專屬謎題、視覺化幾何、段考完整題庫仍待擴充。
- 教材單元排列僅為相近課程架構，正式使用需核對實際學年度翰林版。
- 題目均為原創模板，不收錄教科書原題；部分應用題仍須人工審題。


## v4.1 通關獎勵
- 首次通過每關可以得到一個寶箱，開箱隨機 30–100 金幣；章節最終挑戰額外獎勵 30 金幣。
- 同一關只會領取一次寶箱，防止重玩無限刷金幣；重玩仍可提升星星。
- 金幣可以在獎勵商店購買並裝備三種稱號：尋寶高手、數學達人、解謎傳說。
- 金幣、寶箱領取狀態、稱號與既有 v4 進度均存在同一瀏覽器 localStorage。
- 新增 `public/games.html`：十款數學互動小遊戲。首頁有入口，遊戲成績獨立儲存。

## v4.2 章節冒險區域修正
- 修正切換第二章時仍顯示第一章通用冒險區域與關卡名稱的問題。
- 9 章皆有不同的冒險區名稱、背景色、關卡名稱和說明。
- 第二章六關改為質因數礦坑、公因數之門、倍數時鐘、分數鍛造坊、分數熔爐、礦山大挑戰，搭配其知識點題目。
- 所有章節可自由選取預覽，每章內仍需逐關解鎖。
- 完成章節最後一關後，可直接進入下一冒險區域。
- 可用 `?chapter=2` 直接進入第二章（第 1–9 章均支援）。
- 傳統 `math-quest-puzzle-v4` localStorage 儲存鍵維持不變，原有星星、寶箱、金幣記錄保留。

| P2 | A/B/C 配分模擬考 | 45分鐘；選擇／填充／計算大題配分各100分；**非選擇題只批改最終答案，不給過程分** |

### 試卷配分模型
- A：10選擇×3分＋10填充×4分＋3計算×10分＝100分；其中10填充概念上對應原A卷基本／精熟各5題。
- B：12選擇×4分＋6填充×4分＋4計算×7分＝100分。
- C：12選擇×5分＋7填充×4分＋2計算×6分＝100分。

這是**原創同考點模擬考**，不是逐題複製翰林版官方試卷；A/B/C 是配分格式而不是難度排名。14回與課程依據使用者提供的六份掃描版 A/B/C 試卷與簡答分析。沒有學生實測資料，故不能宣稱題目已經過心理計量校準。

### 進度與升級
- 既有 Math Quest 闖關進度使用 \`math-quest-puzzle-v4\`，新教材中心使用獨立的 \`math-quest-study-v1\`；兩者不互相覆蓋。
- 模擬考會將當下的試卷狀態另存 \`math-quest-study-v1-exam\`，以支援同瀏覽器重新進入後續考。
- 現有 Cloudflare static assets 設定為 \`public/\`。GitHub 成功提交不等於 Cloudflare 已部署成功，須以 Workers → Deployments 的 Production build 為準。

### 驗證摘要
- 隨機題目結構：14回×5級抽樣至少2,800題，驗證必要欄位與唯一正解。
- 模擬考全對回歸：A/B/C 各為100/100；空白答案回歸為0/100。
- 解謎出題：500組分數路線、500組文字委託，驗證選項唯一性。
- UI 提供基本執行測試；仍需在實際手機/桌面瀏覽器完成使用者驗收、檢查文字情境歧義及人工審題。
